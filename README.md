# LIS3DH-Accelerometer-SPI
LIS3DH accelerometer running on STM32 SPI protocol

lis3dh.h: header file defining register addresses and functions
lis3dh.c: function which preforms necessary operations to read acceleration data
main.c: main c function where everything happens

NOTE: project has been programmed to print data to serial monitor in g's, if not necessary for final project simply comment out sections dedicated for serial moniter
